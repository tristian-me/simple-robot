# Simple Robot
A simple robot written in my spare time. It doesn't do much, feel free to clone the
project and do as you like. 

## Devices Used
* ESP32-S3 1.28inch Double Eye Round LCD AIoT Development Board
* PCA9685 breakout board
* 2x Servos
